# MiniTui Desk Tasks

`tuitasks`: A to-do list with due dates in a todo.txt file under `~/.local/share/tuitasks/`, which other todo.txt tools can share. Tasks falling due notify.

```bash
dotnet tool install -g MiniTui.Desk.Tasks
tuitasks
```

It runs on its own in any terminal, and inside [MiniTui Desk](https://www.nuget.org/packages/MiniTui.Desk), where it shows its status in the status line. Linux, x64 and arm64.

Keys and details: [the Tasks README](https://github.com/minitui-org/desk/blob/main/apps/Tasks/README.md). Docs: [minitui.org/desk](https://minitui.org/desk).
