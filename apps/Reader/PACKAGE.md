# MiniTui Desk Reader

`tuireader`: Reads the Markdown and text files of a folder where they are, formatted, and sends a passage to Notes with `Ctrl+N`.

```bash
dotnet tool install -g MiniTui.Desk.Reader
tuireader
```

It runs on its own in any terminal, and inside [MiniTui Desk](https://www.nuget.org/packages/MiniTui.Desk), where it shows its status in the status line. Linux, x64 and arm64.

Keys and details: [the Reader README](https://github.com/minitui-org/desk/blob/main/apps/Reader/README.md). Docs: [minitui.org/desk](https://minitui.org/desk).
