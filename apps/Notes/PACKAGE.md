# MiniTui Desk Notes

`tuinotes`: Markdown notes in plain files under `~/.local/share/tuinotes/`, with a list you filter and an editor that saves as you go.

```bash
dotnet tool install -g MiniTui.Desk.Notes
tuinotes
```

It runs on its own in any terminal, and inside [MiniTui Desk](https://www.nuget.org/packages/MiniTui.Desk), where it shows its status in the status line. Linux, x64 and arm64.

Keys and details: [the Notes README](https://github.com/minitui-org/desk/blob/main/apps/Notes/README.md). Docs: [minitui.org/desk](https://minitui.org/desk).
